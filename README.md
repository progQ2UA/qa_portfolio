## 🧪 Використані типи тестування

| Тип тестування | Опис |
| :--- | :--- |
| **Функціональне тестування** | Перевірка основних функцій (реєстрація, оплата, аудіо-керування, збереження тексту). |
| **UI-тестування** | Перевірка візуальних елементів (шрифт, кнопки, верстка). |
| **Usability-тестування** | Оцінка зручності та інтуїтивності навігації. |
| **Локалізаційне тестування** | Перевірка повного та коректного перекладу українською. |
| **Інтеграційне тестування** | Перевірка взаємодії з зовнішніми сервісами (платіжні шлюзи, push-сповіщення). |
| **End-to-End (E2E) тестування** | Повні сценарії користувача (купівля підписки, доступ до контенту). |
| **Re-Test (Confirmation Testing)** | Повторна перевірка виправлених багів. |
| **Smoke-тестування** | Швидка перевірка критичного функціоналу. |
