# QA Portfolio: ProTalk – English Learning App

> *This portfolio summarizes the testing results for the ProTalk language learning app. It includes test cases and bug reports covering key functional, usability, and localization aspects.*
> *Для українськомовних читачів – скорочена версія нижче / Ukrainian version below.*

---

## 📊 Test Summary

| Metric | Value |
| :--- | :--- |
| **Total Test Cases** | 4 |
| **Passed** | 1 |
| **Failed** | 3 |
| **Bug Reports** | 2 |
| **Test Types Used** | Functional, Usability, Localization |

---

## 🔍 Key Findings

- **Functional Testing** – The app processes core actions (e.g., audio controls, text saving), but 2 out of 3 functional tests failed due to incorrect behavior.
- **Usability Testing** – Identified issues with UI intuitiveness: buttons and navigation are not clear for first-time users.
- **Localization Testing** – Found incomplete Ukrainian translation: some UI elements remain in English after switching language.

---

## 🐞 Bug Reports Overview

- **BUG-001**:  Incomplete Ukrainian localization – UI elements remain in English.
- **BUG-002**:  Incorrect operation of buttons for controlling audio recording

# QA Портфоліо: ProTalk – Додаток для вивчення англійської

> *Це портфоліо підсумовує результати тестування додатку ProTalk. Воно містить тест-кейси та баг-репорти, що охоплюють ключові функціональні, зручності та локалізаційні аспекти.*

---

## 📊 Результати тестування

| Показник | Значення |
| :--- | :--- |
| **Всього тест-кейсів** | 4 |

| **Типи тестування** | Функціональне, Usability, Локалізаційне |

---

## 🔍 Основні знахідки

- **Функціональне тестування** – Додаток обробляє основні дії (аудіо-керування, збереження тексту), але 3 з 4 тестів не пройдено через некоректну поведінку.
- **Usability-тестування** – Виявлено проблеми зі зрозумілістю інтерфейсу: кнопки та навігація неінтуїтивні для нових користувачів.
- **Локалізаційне тестування** – Виявлено неповний український переклад: деякі елементи залишаються англійською після зміни мови.

---

## 🐞 Огляд баг-репортів

- **BUG-001**:  Неповна українська локалізація – елементи інтерфейсу залишаються англійською.
- **BUG-002**:  Некоректна робота кнопок для керування аудіо записом
